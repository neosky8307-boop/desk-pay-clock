[월급 루팡 시계 - GitHub Pages 배포 방법]
1. GitHub에서 새 저장소 생성 (예: desk-pay-clock)
2. 이 폴더 안의 파일 전체(index.html, manifest.webmanifest, sw.js, icons 폴더)를 저장소 루트에 업로드
3. Settings > Pages > Branch: main / (root) 선택 후 Save
4. 1~2분 뒤 https://<계정>.github.io/desk-pay-clock/ 접속
5. 폰 크롬에서 열고 메뉴(⋮) > "홈 화면에 추가" 또는 "앱 설치"
